# Project Customizations

## ML Folder Learning Notes Rule
After successfully executing any task related to the `ML` folder, always append an update to `ML/learning_notes.md`. 
In this update, formally document the operations performed. The explanation should be highly technical and rigorous, avoiding childish analogies. Detail exactly *what* the technology is, *why* it is utilized in an architectural or engineering context, and clearly break down the *syntax* of any relevant commands executed. Do this step at the very end of the task.
